# Neuro-Symbolic Multimodal Learning for Biomass Estimation from Pasture Imagery Using Logical Tensor Networks

## Overview

This project proposes a Neuro-Symbolic Artificial Intelligence framework for pasture biomass estimation by integrating neural representation learning with Logical Tensor Networks (LTNs). The model combines data-driven feature extraction with domain-specific agronomic knowledge to improve prediction accuracy, interpretability, and logical consistency.

Unlike conventional machine learning approaches, the proposed framework explicitly incorporates biological constraints during training through differentiable logical reasoning. This enables the model to generate physically plausible biomass estimates while maintaining strong predictive performance.

## Methodology

The framework consists of three key components:

- Neural feature learning from environmental and biomass-related variables.
- Shared latent representation learning for multimodal information fusion.
- Logical Tensor Network reasoning for enforcing agronomic constraints.

Domain knowledge is incorporated through logical rules governing biomass conservation, vegetation dynamics, monotonic growth relationships, and physical feasibility constraints.

## Key Features

- Neuro-Symbolic learning architecture
- Logical Tensor Network (LTN) integration
- Constraint-aware biomass prediction
- Explainable and interpretable decision process
- Rule satisfaction analysis
- Publication-grade scientific visualizations

## Results

Experimental evaluation demonstrates that logical constraint enforcement significantly improves rule satisfaction and semantic consistency compared to purely neural approaches. The proposed model produces biologically meaningful biomass predictions while preserving predictive accuracy.

## Applications

- Precision Agriculture
- Biomass Monitoring
- Sustainable Grazing Management
- Environmental Analytics
- Agricultural Decision Support Systems
